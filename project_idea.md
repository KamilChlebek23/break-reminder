# BreakReminder application idea

### Main goal
Programmers spend too much time working on computer without taking a break.
I would like to develop a application that reminds programmers about need of taking a break.


### MVP
- Application runs in Windows 11.
- Application is easy installable.
- Application is widget.
- Application has UI.
- Application has configurable time interval of break eg. every 1 hour.
- Application signals user about need of taking break with popup and/or voice. It must be also configurable.
- Application allows user to add reminders about custom activities eg. 'Visit to dentist'.


### Success factors
- User can install application in Windows 11.
- Application informs user about need of taking break in right time.
- Application allows user to add reminders about custom activities.
